# Страницы личного подключения rclone

Публичный информационный сайт о личном OAuth-подключении PrinterOMG к Google Drive:

- `index.html` — описание приложения;
- `privacy/index.html` — политика конфиденциальности;
- `terms/index.html` — условия использования.

Статический HTML и CSS, без JavaScript, аналитики, форм, внешних шрифтов и сборки.
Для публикации используется GitHub Pages: ветка `main`, корень репозитория.

Для локального просмотра:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Этот репозиторий содержит только страницы сайта. Учётные данные, конфигурация rclone
и файлы Google Drive должны храниться вне него.
